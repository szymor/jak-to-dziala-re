# CD inventory

Source: `Jak To Działa.iso`, ISO 9660 volume `DKMMTWTW__CDFS_`, mastered 1999-01-23, 2534 files / 218 dirs, 280 MiB.
The machine-readable list is [`inventory/manifest.csv`](inventory/manifest.csv), generated by `tools/manifest.py`.

Reproduce:

```bash
tools/wine-setup.sh setup
```

```bash
python3 -I tools/manifest.py work/cd docs/inventory/manifest.csv
```

```bash
python3 -I tools/dkmm_strings.py work/cd work/dkmm
```

```bash
python3 -I tools/unpack_szdd.py work/cd/DKCODE work/redist
```

The first command extracts the ISO to `work/cd` and builds the Wine prefix.

## 2. File naming

Most media names follow `SSSS n R [k] [A|S]`:

- `SSSS`: subject code (`AIRP` = airplane, `QCAM` = principle "cams", …). Principles start with `Q`, timeline with `TT`, workshop `WWWW`, A–Z `AZAZ`.
- `n`: page/variant index (0–9).
- `R`: role (see the table below).
- `k`: index of the media item attached to that image (0–9, sometimes A–L for hub screens: `WWWW0MAA.ANI` … `WWWW0MLA.ANI`).
- `A`: animation (`.ANI`), `S`: sound (`.WAV`).

| Role | Count | Typical size | Meaning (from viewing samples) |
|---|---:|---|---|
| `M` | 319 | 540×450 (articles), 560×410, up to 640×480 | Main page of a subject, with title, body text and labelled illustration all baked in |
| `N` | 462 | 181×~119 | Callout note shown when a label on the main page is clicked |
| `Z` | 266 | ~355×386 | Zoom/detail pop-up, often with animations `…Z0A.ANI` |
| `X` | 131 | ~275×324 | Extra explanation pop-up. Red words are glossary links, so they must be hotspots in the data. |
| `J` | 132 | 237×~132 | "Patrz też" (see also) panel listing related machines |
| `P` | 77 | 242×177 | "Pokrewne działy nauki i techniki" (related principles), in `RELA/` |
| `R` | 22 | ~296×250 | "Urządzenia pokrewne" (related machines) for a principle |
| `G` | ~64 | | Glossary entry `Gxxx000G.DIB` in `GLOS/` (a separate pattern, not matched by the manifest's role regex) |

Other schemes: `AZnn0M.DIB` (A–Z pages), `TTnn0M.DIB` (timeline pages), `Ixxxx0M.DIB` (inventor pages), `HELPpMnn.DIB`, `OPTI0n.DIB`, `INDE00.DIB`, `NAV/FRAME{TOP,BOT,SID}.DIB`.

**All article text is pre-rendered into the bitmaps.** Only the Index screen draws text at runtime (its list and edit field).

## 3. Formats

### DIB (1704 files): solved
- Plain Windows BMP, `BITMAPINFOHEADER`, **8 bpp RLE8** (one file, `WINGDRV/.../VGALOGO.RLE`, is RLE4 and irrelevant).
- **All 1703 game bitmaps carry the identical palette** (sha1 `29c848a1379b…`). Index 0 is black, 1–9 are white placeholders, 246–254 black placeholders and 255 white. That is the classic WinG *identity palette* layout: the 20 system colours are reserved and the art uses indices 10–245. The port can use one global palette.
- Pop-ups are opaque bitmaps; their title strip and checkered shadow are drawn by the program (see [formats/dkmm.md](formats/dkmm.md)).

### WAV (100 files): solved
- 97 × MS-ADPCM, 22050 Hz, 4-bit, mono. 3 × PCM 8-bit 22050 Hz mono. SDL3 `SDL_LoadWAV` handles both.

### ANI (497 files): see [formats/ani.md](formats/ani.md)
495 valid `funky!` animations; the two `PRINCIPL/QLVR` files are damaged leftovers.

### TWTW.PNG (DKMM data file, 650 382 bytes): see [formats/dkmm.md](formats/dkmm.md)
- Big-endian although the EXE is x86, which suggests a Mac-hosted authoring tool.
- Pool contents: 1380 free-text strings (index titles such as "Akumulator samochodowy - bateria", subject titles, button labels, help page names), 202 directory strings (`\ARTICLE1\AIRP\`, …), 2213 resource names (file stems without extension, e.g. `AIRP0m0a`), 13 relative paths (`nav\navb0m0a`, …) and keywords (`normal`, `none`, `zoom`, `hand`, `wipe_down`, …): cursor names and transition effects.
- Strings are **interned**: each text appears once, so the pool order says nothing about which directory a name belongs to. That link lives in the records.
- Cross-check: every resource-like string resolves to a CD file, and **2283 of 2300 media files are referenced**. Of the 17 unreferenced files, `AZAZ/DIAL.WAV` is named in the EXE: the A–Z dial plays `DIAL` when it opens (FUN_1048_e1c8). The other 16 are named nowhere in the EXE or the data, so they are leftovers: `NAV/ZM.WAV`, `NAV/RZM.WAV`, `ARTICLE2/LITC/LITC0Z1.DIB`, `PHON0MAA/0MCA.ANI`, `STRI0Z1S/0Z2S.WAV`, `HELPAMT4.DIB`, `QCOM1X0A.ANI`, `QFRI1Z0S.WAV`, `QHEA{1,2,3}Z0A.ANI`, `QHEA1Z1A.ANI` and the two damaged `QLVR` animations.

### TWTW.EXE
Resources and string tables: [formats/exe_resources.md](formats/exe_resources.md).
Win16 NE, 86 segments (12 code, 74 data; several 64 KB data segments). Imports `KERNEL, GDI, USER, WIN87EM, WING, COMMDLG, MMSYSTEM`. MSVC 1.5x. The EXE contains window/panel class names such as `NavHotspot`, `NavPanel` and `AZDial`, plus parser messages for the panel/template/event/action script language. Static analysis: [re/TWTW_EXE.md](re/TWTW_EXE.md).

### Compressed redistributables in `DKCODE/*.??_`
- 5 files are **SZDD** (WinG 1.0: `WING.DLL`, `WINGDE.DLL`, `WINGDIB.DRV`, `WINGPAL.WND`, `WING32.DLL`). 7-Zip unpacks them, and `tools/unpack_szdd.py` restores the names. They are needed to run the original under Wine.
- 35 files are **KWAJ**. 7-Zip can't read them. They were not unpacked: they were identified from their names, and the port needs none of them. They are the standard Windows 3.1 add-ons that the installer sets up on a bare system:
  - *Video for Windows 1.1*: `MSVIDEO`, `AVIFILE`, `AVICAP`, `MCIAVI`, `DISPDIB`, `DCISVGA`, `DVA.386`, the codecs `ICCVID` (Cinepak), `IR21`/`IR32`/`IYVU9` (Indeo), `MSVIDC`, `MSRLE`, and `MPLAYER` with its help and registry files. Not needed: there is no AVI on the CD, and all animation is in the custom ANI format.
  - *Audio Compression Manager*: `MSACM.DLL/.DRV`, `MSADPCM.ACM`, `IMAADPCM.ACM`, `ACMCMPRS`. The original does need this group indirectly: MMSYSTEM passes the MS-ADPCM WAVs to ACM for decoding. Wine provides its own built-in ACM, and the port doesn't need it because SDL3 decodes MS-ADPCM itself.
  - *OLE2*: `OLE2*`, `COMPOBJ`, `STORAGE`, `TYPELIB`, `STDOLE`, `MCIOLE`, `CLEANUP.REG`.
  - *Misc*: `CTL3D` and `MAP_WIN.HLP`. These and OLE2 are probably for the installer or for opening `CZYTAJ.WRI` in Write; not checked against `DKSETUP`.
  - `TWTW.EXE` imports none of these DLLs and doesn't mention MSVIDEO, AVIFILE, COMPOBJ, OLE2 or MCIAVI anywhere.

## 4. Running the original (reference)

- `tools/wine-setup.sh run`: Wine 11 (WoW64) with the CD mapped as `D:` (cdrom) and native WinG.
- `tools/orig.sh start|shot|click|key|stop`: the same, headless on Xvfb `:77`, driven by xdotool. Verified: title screen, title animation, then a click leads to the Workshop hub with the navigation bar (Warsztat, Urządzenia, Działy nauki, Historia, Wynalazcy, Wróć, Indeks, Opcje, Pomoc). The app's outer window is 640×480 including the Win3.1 frame and caption.
- Sound output under Xvfb was not checked.
